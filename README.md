# Tabela de Comparação de Preços

Projeto educacional para aprender HTML semântico e acessibilidade em tabelas.

## 📋 Sobre o Projeto

Uma página HTML single-page que compara três planos de assinatura usando uma tabela HTML real, semântica e acessível. Desenvolvido como parte do [Roadmap.sh - HTML Fundamentals](https://roadmap.sh/packs/html).

## ✨ Características

- ✅ Estrutura semântica com `<header>`, `<main>`, `<footer>`
- ✅ Tabela acessível com `<caption>`, `<thead>`, `<tbody>`
- ✅ Atributos `scope="col"` e `scope="row"` para acessibilidade
- ✅ Célula mesclada com `colspan`
- ✅ Metadados HTML corretos (`<title>`, `<meta charset>`, `<meta viewport>`)

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/roadmap-pricing-comparison-table.git
```

2. Abra o arquivo `index.html` em seu navegador

## 📚 Aprendizados

- Quando e como usar tabelas HTML
- Importância do atributo `scope` para acessibilidade
- Estrutura semântica de documentos HTML
- Boas práticas de caption e rowspan/colspan
